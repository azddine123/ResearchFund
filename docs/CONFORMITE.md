# ResearchFund — périmètre de conformité
Le texte de mission fourni est la référence de cette adaptation. Le cahier pédagogique original n’a pas été joint à cette session : sa conformité complète reste à vérifier avec l’enseignant.

| Exigence | Réalisation |
|---|---|
| Dons et gouvernance | Contrats inchangés, 1 ETH = 1 000 CFD, aucun rendement |
| Catalogue scientifique | 8 domaines, filtres croisés catégorie/statut |
| Création / détails | Métadonnées v2 IPFS, compatibilité ancienne, informations déclaratives séparées des données on-chain |
| Financement | Confirmation des conditions, wallet, contribution, CFD, remboursement, historique |
| DAO / sécurité | Snapshot, quorum 20 %, majorité stricte, délais et 2-sur-3 conservés |
| Tableau de bord | Valeurs issues des contrats, périmètre de chargement annoncé |
| Recherche / documents | Étapes informatives, références CID bornées ; pas d’upload binaire |
| Anomalies | Heuristiques transactionnelles, aucune détection de fraude scientifique |
| Démonstration | Quatre projets fictifs ; retrait, annulation, remboursement et vote ouvert |
| Preuves | Résultats ResearchFund dans evidence ; historiques clairement archivés |

Limites : pas de certification scientifique, pas de nouveaux types de vote, pas de paiement par tranche, pas de déploiement public revendiqué. MetaMask réel reste à tester manuellement.
